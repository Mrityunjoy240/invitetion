# Anamika & Subhadip · Wedding Invitation
## শুভ বিবাহ · 13 December 2026

A royal Bengali digital wedding invitation for **Anamika & Subhadip**.

### Features
- Cinematic traditional temple opening with parting doors and drifting marigold petals
- Live countdown timer nestled in the architectural pavilion
- Multilingual Bengali & English typography (Tiro Bangla & Cormorant Garamond)
- Ceremonial event itineraries with one-tap Google Calendar integration
- Venue showcase with direct Google Maps directions
- Moments gallery and WhatsApp invite sharing

### Development

To run locally:

```sh
pnpm install
pnpm dev
```

Then visit [http://localhost:3000](http://localhost:3000) (or the port indicated in the terminal).

### Build

```sh
pnpm build
```
